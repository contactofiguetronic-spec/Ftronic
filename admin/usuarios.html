Ayuda — Gestión de Usuarios

Este módulo permite administrar las cuentas de acceso al ERP de Figuetronic. Cada usuario tiene un username, contraseña, rol y nivel de acceso.

Crear un usuario

Haga clic en "Nuevo", complete los datos personales (nombre, email, tipo) y guarde. Luego vaya a la pestaña Cuenta para configurar username, contraseña y rol.

Tipos de usuario

  • Empleado — Personal interno del taller (recepcionistas, técnicos, etc.)
  • Cliente — Usuarios externos con acceso al portal
  • Administrador — Acceso elevado para gestión del sistema

Niveles de acceso

  • Nivel 1 (Admin): Acceso total — configuración, permisos, auditoría
  • Nivel 2 (Gerente): Gestión completa excepto configuración admin
  • Nivel 3 (Recepcionista): Recepción, clientes, órdenes de trabajo, agenda
  • Nivel 4 (Técnico): Ejecución OT, inventario, diagnósticos
  • Nivel 5 (Vendedor): Presupuestos, ventas, clientes
  • Nivel 6 (Solo Lectura): Consulta sin modificar datos

Roles y permisos

Los roles son conjuntos de permisos predefinidos (Recepcionista, Técnico, etc.). Puede asignar permisos adicionales o quitar permisos específicos desde la pestaña Permisos de cada usuario.

Solicitudes de registro

Los usuarios se registran desde la página pública (/admin/registro.html). Las solicitudes pendientes aparecen con un indicador rojo. Puede aprobarlas (creando la cuenta) o rechazarlas.

Actividad

La pestaña Actividad muestra un registro de las acciones del usuario: inicios de sesión, creaciones, modificaciones y eliminaciones.
