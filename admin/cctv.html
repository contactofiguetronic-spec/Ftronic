Videovigilancia del Taller

Monitorea las cámaras Dahua del taller, abre la transmisión en la nube de Dahua y administra los dispositivos P2P registrados.
Modo de visualización: Configure la IP pública / DDNS del dispositivo para acceder vía port-forwarding desde el servidor. El botón "Ver en vivo" carga la transmisión MJPEG directamente. Si el DVR no es alcanzable, use "Abrir en nube Dahua" para acceder vía la app DMSS con el ID P2P. Para port-forwarding, necesita abrir los puertos HTTP (8080 recomendado), RTSP (554) y SDK (37777) en el router.
