Servicios y Trabajos

Catálogo de servicios que ofrece el taller con precios, tiempos estimados y descripción detallada de cada trabajo.
Función
Define el catálogo de servicios del taller: diagnóstico, reparación, mantenimiento, etc. Cada servicio tiene un precio base y tiempo estimado que se usa al crear presupuestos.
